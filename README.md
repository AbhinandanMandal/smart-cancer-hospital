# Smart Cancer Hospital Decision System

An interactive academic demonstration of a rule-based **Smart Cancer Hospital Decision System** designed to explore patient-data processing, priority assignment, system boundaries, feedback mechanisms, failure cases, and iterative system improvement.

## Overview

The Smart Cancer Hospital Decision System is a conceptual, rule-based decision-support simulation.

The system accepts a set of patient-related inputs and processes them through predefined rules to assign one of four simulated priority levels:

- Immediate Emergency
- High Priority
- Medium Priority
- Low Priority

The primary objective of this project is not to build a clinically validated medical system, but to demonstrate how a rule-based decision system can be designed, analyzed, tested, and iteratively improved when previously unseen or insufficiently represented scenarios expose limitations.

The interactive website demonstrates the complete lifecycle:

```text
Patient Data
     ↓
Data Collection
     ↓
Decision Processor
     ↓
Rule Evaluation
     ↓
Priority Assignment
     ↓
Doctor Review
     ↓
Feedback
     ↓
System Update
     ↺
